====================
Apricos Architecture
====================

64KB of main address space
256 bytes of stack space (shared with main address space, page 0xFF00-0xFFFF)

8 bit ISA, 16 possible operations.


23 registers:

$ip    16-bit instruction pointer
$mr    16-bit memory address register
$dr    8-bit memory data register
$ir    16-bit instruction register
$ia    8-bit optional instruction argument
$sp    8-bit Stack register (Or stack pointer)
$fr    8-bit CPU status flags register
$a0-15 16 8-bit accumulators

Flags register: [  .  .  .  .  O  N  Z  P  ]
O = Unsigned carry out of bit 7 (set by ADD and SPOP ADD; cleared by other flag-setting instructions)
N = Negative result
Z = Zero result
P = Positive result

=====
 ISA
=====

OP Code	|  Instruction	|  Description
-----------------------------------------------------------------------------------------
0000	|  ADD		|  Add a value to the currently selected accumulator
0001	|  AND		|  AND a value with the currently selected accumulator
0010	|  OR		|  OR a value with the currently selected accumulator
0011	|  XOR		|  XOR a value with the currently selected accumulator
0100	|  NOT		|  NOT the currently selected accumulator
0101	|  SHF		|  SHIFT the currently selected accumulator either left or right
0110	|  LD		|  Load a value from memory into the currently selected accumulator
0111	|  LDI		|  Load a value from memory using an immediate PC offset
1000	|  ST		|  Store the currently selected accumulator to memory
1001	|  STI		|  Store the currently selected accumulator to memory using an immediate PC offset
1010	|  STK		|  Stack push/pop
1011	|  LA		|  Store an immediate address into the MAR or the currently selected accumulator
1100	|  BR		|  Branch
1101	|  PRT		|  Port I/O
1110	|  ASET  	|  Set the current active accumulator
1111	|  RESERVED	|  Reserved opcode (executes as a NOP)

===================
Instruction details
===================
x = don't care
(n) = operand size
$ar = currently selected accumulator

-----
 ADD
-----

0000 imm(4)

$ar += imm

-----
 AND
-----

0001 imm(4)

$ar &= imm

----
 OR
----

0010 imm(4)

$ar |= imm


-----
 XOR
-----

0011 imm(4)

$ar ^= imm

-----
 NOT
-----

0100 xxxx

$ar = ~$ar (bitwise complement)

-----
 SHF
-----

0101 direction(1) count(3)

if direction == 1:
    $ar >> count+1
else
    $ar << count+1

Note that count is offset by 1.
This means that 000 will correspond to
a shift of 1, 001 to a shift of 2, etc.
Both directions shift in zeros.


----
 LD
----

0110 addressWrite(1) writeHigh(1) xx

if addressWrite == 1:
    if writeHigh == 1:
        $ar = high byte of $mr
    else
        $ar = low byte of $mr
else
    $ar = memory[$mr]

Note: the addressWrite form reads a byte of $mr into $ar.
$mr is not modified. (It is ST, not LD, that writes to $mr.)


-----
 LDI
-----

0111 xxxx
ipoffset(8)

$mr = $ip + ipoffset
$ar = memory[$mr]

Note: $ip has already been incremented past the 2-byte instruction, so
the base address is the LDI opcode address + 2. The offset is unsigned
(forward-only, 0-255). $mr is overwritten with the effective address.


----
 ST
----

1000 addressWrite(1) writeHigh(1) xx

if addressWrite == 1:
    if writeHigh == 1:
        $mr = ($mr & 0x00FF) | ($ar << 8)
    else
        $mr = ($mr & 0xFF00) | $ar
else
    memory[$mr] = $ar

Note: the addressWrite form replaces one byte of $mr and preserves the
other (it does not OR).


-----
 STI
-----

1001 xxxx
ipoffset(8)

$mr = $ip + ipoffset
memory[$mr] = $ar

Note: same addressing as LDI (base = opcode address + 2, unsigned
forward-only offset, $mr overwritten).


-----
 STK
-----

1010 pop(1) operation(3)

The stack lives in memory page 0xFF: the accessed cell is
memory[0xFF00 + $sp]. $sp wraps mod 256.

if pop == 1:
    if operation == 100b:
        $ar += memory[0xFF00 + $sp]

    else if operation == 101b:
        $ar &= memory[0xFF00 + $sp]

    else if operation == 110b:
        $ar |= memory[0xFF00 + $sp]

    else if operation == 111b:
        $ar ^= memory[0xFF00 + $sp]

    else:
        $ar = memory[0xFF00 + $sp]

    $sp = $sp - 1

else:
    $sp = $sp + 1
    memory[0xFF00 + $sp] = $ar

-----
 LA
-----

1011 loadHigh(1) destination(1) xx
address(8)

if loadHigh == 0:
    if destination == 0:
        $mr[0-7] = address
    else:
        $ar = address
else:
    if destination == 0:
        $mr[8-15] = address
    else:
        $ar = address

----
 BR
----

1100 n(1) z(1) p(1) useImmAddress(1)
immAddress(8)

if (n == 1 && $fr[N] == 1) || (z == 1 && $fr[Z] == 1) || (p == 1 && $fr[P] == 1):
    if (!useImmAddress):
        $ip = $mr
    else:
        $ip[0-7] = immAddress

Note: at execution time $ip already points past the 2-byte instruction
(opcode address + 2), so the immediate form branches within the page
containing opcode+2. At reset the flags register is all zeros, so no
branch (not even BRnzp) is taken until a flag-setting instruction has run.



-----
 PRT
-----

1101 direction(1) id(3)

if direction == 1
    write data to port #id
else
    read data from port #id

Note: a port read also updates the N/Z/P flags from $ar.


------
 ASET
------

1110 aID(4)

Set the current active accumulator to accumulator #aID

Note: ASET also updates the N/Z/P flags from the newly selected
accumulator.
